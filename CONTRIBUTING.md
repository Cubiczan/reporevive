# Contributing to RepoRevive

Thank you for your interest in contributing! 🎉

## How to Contribute

1. **Fork** the repo and **clone** your fork
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes with tests
4. Run the test suite: `cd backend && npm test`
5. Commit with a conventional message: `git commit -m "feat: describe your change"`
6. Push and open a **Pull Request**

## Development Setup

See the [README Quick Start](README.md#quick-start) section.

## Code Style

- Use `const`/`let`, never `var`
- Async/await over callbacks
- Add JSDoc for exported functions
- Keep functions small and single-purpose

## Reporting Bugs

Open an issue with:
- Steps to reproduce
- Expected vs actual behavior
- Your Node.js version and OS

## Feature Requests

Open an issue tagged `enhancement` with your use case.
