## 2. Project Details

### Project Description (max 100 words)

RepoRevive is an AI-powered tool that analyzes and revives abandoned GitHub repositories. It uses the GitHub API to calculate a Staleness Score and Revival Potential Score across six weighted dimensions, then leverages Anthropic's Claude AI to generate a personalized revival plan, professional README, good-first-issue suggestions, and an interactive checklist. In under 5 minutes, maintainers receive a complete, actionable roadmap to bring their dormant codebase back to life — from quick wins to a 6-month strategic roadmap and community re-engagement strategy.

## 3. Improvements Made (v1.0 → v2.0)

The following improvements were made during the hacking period:

| Improvement | Details |
|---|---|
| **AI Revival Plans** | Integrated Claude Opus to generate personalized quick wins, short-term goals, 6-month roadmap, and community strategy per repository |
| **Staleness Scoring Algorithm** | Upgraded from a basic "days since last commit" check to a 6-dimension weighted algorithm covering commits, issues, releases, contributors, stars, and archive status |
| **Revival Potential Score** | New score (0–100) assessing whether a repo is worth reviving, based on stars, forks, contributors, open issues, and documentation quality |
| **AI README Generator** | New endpoint that generates a professional, repo-specific README.md using Claude AI |
| **Good First Issues Generator** | AI suggests 5 beginner-friendly issues with labels to attract new contributors |
| **Interactive Revival Checklist** | Structured 20-task checklist with effort estimates across 5 categories: Documentation, Legal, CI/CD, Community, Releases |
| **Language Breakdown Visualization** | Visual percentage breakdown of repository languages using proportional color bars |
| **Security Hardening** | Added Helmet.js headers, express-rate-limit (100 req/15min), CORS configuration, and input validation |
| **Caching Layer** | 5-minute TTL in-memory cache for GitHub API responses to improve performance and reduce rate limit usage |
| **Test Suite** | Complete Jest test suite covering API endpoints, staleness scoring, and revival potential algorithms |
| **CI/CD Pipeline** | GitHub Actions workflow for lint, test, build, and security audit on every push |
| **Docker Support** | Full docker-compose setup with multi-stage Dockerfiles for both frontend and backend |
| **Health Grade** | Added A–F health grade combining staleness and potential scores for quick assessment |

## Local Testing Instructions

```bash
# 1. Clone the repo
git clone https://github.com/icohangar-ops/reporevive.git
cd reporevive

# 2. Set up backend environment
cd backend
cp .env.example .env
# Add GITHUB_TOKEN and ANTHROPIC_API_KEY to .env

# 3. Install and run backend
npm install
npm run dev
# → API running on http://localhost:5000

# 4. In a new terminal, start frontend
cd ../frontend
npm install
npm start
# → App running on http://localhost:3000

# 5. Run tests
cd ../backend && npm test
```

**Or with Docker:**
```bash
cp backend/.env.example .env
# Edit .env with your API keys
docker-compose up --build
# → http://localhost:3000
```
